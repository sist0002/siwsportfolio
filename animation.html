//emergency site - starlight (stjernehimmel)

For this theme for my studies, I made an "emergency-site" - a website that revolves around a fictional emergency.

My case was a deadly global pandemic, where small isolated space capsules, produced by the company STARLIGHT, became the last possible outcome for survival.

The website includes news articles, how to guides and interactive infographics - and it also has a dark-mode function.

PROCESS

//style-reference

Through my studies, I have learned about a few different styles, including retro-design, modernism, postmodernism and futurism.

//vector graphics

I have drawn vector graphics in Adobe Illustrator for my website, by using pen-tool.

Vector-graphics (svg) can be incooperated in your HTML, because it consists of code. I have therefore made my svg interactive, so an info box appears, when clicking on the moon.

//forms

HTML forms are often used for contact formulas and consists of interactive areas to be filled out by the user.

On this theme, through my studies, I learned how to correctly set up these formulas in HTML, and the different elements it consists of (radio, text, email).

Furthermore, I made a summary section by using JavaScript, to show a summary of the user inputs in the formula.

//javascript

I used JavaScript to impliment dark mode on my website - as well as a pan-function, infographics, dialogue boxes and a summary section.

By making these, I learned about constants, functions and if / else.
